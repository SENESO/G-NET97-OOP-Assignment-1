# G-NET97 OOP — Assignment 1: Encapsulation, Indexers & Structs

C# console application demonstrating OOP fundamentals through a shipment delivery-management system.

## Concepts Covered

- **Encapsulation** — `Shipment` class with validated properties
- **Indexer** — `DeliveryCenter` with lookup by index or tracking code
- **Struct** — `DeliveryAddress` struct illustrating value-type copy semantics

`Program.cs` also includes answered theoretical questions on struct vs. class and encapsulation.

## How to Run

```bash
dotnet run
```

## Tech Stack

- C# / .NET
- Console Application
